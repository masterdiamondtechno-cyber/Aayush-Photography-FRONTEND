# आयुष्याची फोटोग्राफी | Tushar Pulate Institute of Photography & Film Making

Official web application and student/staff management portal for **Tushar Pulate Institute of Photography & Film Making** (आयुष्याची फोटोग्राफी - Journey From Nothing To Everything).

## Features
- **Cinematic Photography Theme**: Luxury dark aesthetics (`#090909`), warm gold accents (`#FFC629`), and typography matching the Vercel photography showcase.
- **Dual Language Support (Marathi & English)**: Complete bilingual switching across the site with persistent user preference.
- **Courses & Masterclasses**: 30-Day Masterclass curriculum covering Studio Lighting, Wedding & Pre-wedding, Cinematography, Drone Shoots, and Post-Processing.
- **Interactive Syllabus Modal**: Deep dive into daily modules, fees, booking amount (₹5,000), and direct WhatsApp enquiry.
- **Facilities & Equipment**: High-end Godox/Profoto studio lighting, editing suite (M-series Mac, DaVinci Resolve, Lightroom), chroma setup, gimbal & drone labs.
- **Cinematic Video Gallery**: HTML5 video showcases of student practicals and field projects.
- **Interactive FAQ & WhatsApp Enquiry**: Direct enquiry generator with automatic message formatting.
- **Portal Access**: Integrated portals for Students, Instructors, Management, and SuperAdmin via `/login`.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Photography Design System (`src/styles/photography.css`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Fonts**: Cinzel, Noto Sans Devanagari, Plus Jakarta Sans

## Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
